# Breast Cancer Prediction — Logistic Regression Baseline

This repository contains a focused, end-to-end baseline implementation that uses **Logistic Regression** to predict whether a tumor is **benign** or **malignant** from the Breast Cancer Wisconsin (Diagnostic) features.

> **Important:** This notebook is a baseline. Current recorded performance (as run) is **Accuracy = 0.40 (40%)**. That indicates the pipeline works but needs serious improvements before any real-world use.

---

## What’s included

- `Breast Cancer Prediction.ipynb` — the Jupyter notebook with the full workflow:
  - Data loading and exploration
  - Preprocessing (StandardScaler)
  - Model training with `LogisticRegression`
  - Evaluation using `accuracy_score`
- (No saved model file included in the notebook by default.)

- **Model**: Logistic Regression (scikit-learn)
